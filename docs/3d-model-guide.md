# 3D 宠物模型制作与导入

桌面宠物当前只接受二进制 glTF 文件，也就是 `.glb`。GLB 会把网格、材质、贴图和动画集中在一个文件中，比 `.gltf`、`.obj` 或 `.fbx` 更适合直接导入应用。

## 推荐工具

### 1. Blender：完全免费，最推荐

地址：https://www.blender.org/

适合已有模型转换、手工建模、减面、调整朝向、绑定骨骼和添加动画。Blender 是开源桌面软件，没有生成次数限制。

导出步骤：

1. 在 Blender 中导入或制作模型。
2. 确认模型站立方向正确，脚底靠近地面，正面朝向相机。
3. 选择“文件 → 导出 → glTF 2.0”。
4. Format 选择 `glTF Binary (.glb)`。
5. 需要动画时启用 Animation，并尽量保留名为 Idle、Walk 的动画。
6. 导出后，在桌面宠物设置页点击“导入 GLB”。

### 2. Meshy：文字或图片生成，提供免费额度

地址：https://www.meshy.ai/

适合用文字描述或单张角色图片快速生成模型。免费额度和下载权限可能随平台规则变化，生成前应查看当前套餐。生成后优先下载 GLB；如果只能下载 FBX、OBJ，再用 Blender 转为 GLB。

### 3. Tripo AI：文字或图片生成，提供免费额度

地址：https://www.tripo3d.ai/

适合快速生成卡通角色和简单道具。通常有注册免费额度，具体点数、导出格式和商业授权以网站当前说明为准。

### 4. Hugging Face Spaces：开源模型在线演示

地址：https://huggingface.co/spaces

可搜索 `Hunyuan3D`、`TripoSR`、`Stable Fast 3D`。很多演示可以免费试用，但可能排队、临时休眠或限制下载。不要向不可信的 Space 上传私密图片。

### 5. Mixamo：免费自动绑骨骼和角色动画

地址：https://www.mixamo.com/

适合给人形角色自动绑骨骼并添加 Idle、Walk 等动画。Mixamo 通常导出 FBX，需要使用 Blender 导入 FBX 后再导出 GLB。需要 Adobe 账号，授权范围以其当前条款为准。

## 模型优化建议

- 三角面数量建议低于 50,000，越低越适合常驻桌面运行。
- 贴图建议不超过 2048 x 2048，普通卡通模型使用 1024 x 1024 通常足够。
- 尽量只使用一到两个材质，减少实时渲染开销。
- 删除看不见的内部网格、重复物体和无用动画。
- 模型应以 Y 轴向上，脚底在最低点附近。
- 文件建议控制在 20 MB 以内；应用硬性限制为 100 MB。
- 应用会自动把模型缩放到窗口内，但极端长宽比例仍可能显得过小。

## Blender 转换常见格式

- `FBX → GLB`：Blender 选择“文件 → 导入 → FBX”，检查材质和动画后导出 glTF 2.0。
- `OBJ → GLB`：同时保留 `.mtl` 和贴图文件，导入 OBJ 后检查贴图再导出。
- `VRM → GLB`：安装可信的 VRM Add-on for Blender 后导入，检查材质兼容性，再导出 GLB。
- `GLTF → GLB`：导入 `.gltf` 后直接以 `glTF Binary (.glb)` 导出。

## 导入失败排查

1. 确认文件扩展名是 `.glb`，不是只改了后缀名。
2. 用 Blender 或 Windows 3D Viewer 打开文件，确认模型本身有效。
3. 如果模型使用 Draco、Meshopt 或特殊材质扩展，先用 Blender 重新导出标准 GLB。
4. 如果贴图丢失，重新导出时确认贴图已打包进 GLB。
5. 如果模型全黑，检查法线、材质和贴图色彩空间。
6. 如果模型没有动作，确认 GLB 中确实包含动画轨道；无动画模型仍会使用应用提供的轻微待机浮动。

免费额度、服务条款和商业授权会变化。准备发布或商用模型前，应在对应网站确认最新许可。
