# 桌面宠物 3D 外观设计

日期：2026-08-03
状态：设计已确认，待实现

## 背景与目标

在现有 2D 像素桌面宠物基础上，以**增项**方式提供 3D 外观能力：
- 保留现有像素风格与全部数据/交互；
- 提供三个 3D 外观槽位，默认内置三款程序化 3D 宠物，可替换为外部导入的 .glb 模型；
- 3D 与 2D 为**同一宠物实体，可切换外观**，等级/心情/记忆/AI 对话/AI 提供商全部共用一套数据。

## 需求确认要点

1. 3D 形态：体素方向（保留像素风）+ 外部 GLB 混合。
2. 三个 3D 模型槽位：可导入外部 .glb，也可选内置款，灵活自由。
3. 与现有 2D 像素宠物：同实体、可切换外观、共用一套数据。
4. 槽位默认安排：默认三款内置（体素猫/兔/熊），可被外部模型替换。
5. 3D 外观下保留全部互动：戳宠物触发 AI/预设回应 + 立体动画、可拖动、待机呼吸/摇尾巴动画、表情变化。

## 技术方案

- **渲染内核**：Three.js（Electron 透明窗口原生支持 WebGL）。
  - 体素宠物：Three.js 用 InstancedMesh 直接把像素堆成方块组，代码生成，无外部文件。
  - 外部 .glb：用 GLTFLoader 从磁盘/file:// 加载，统一包围盒缩放适配窗口。
  - 动画：体素走程序化动画（呼吸/摇尾巴/眨眼用代码驱动变换）；.glb 若自带动画剪辑则直接播放。
- **同一窗口切换**：在现有宠物透明窗口内，Canvas 2D 与 WebGL 共存切换，尺寸/拖动/气泡锚点逻辑复用。

## 架构分层

### 主进程 (main.js)
- 窗口管理/气泡/聊天/IPC 全部复用，不破坏现有逻辑。
- 新增少量 IPC：`pet:setAppearance3D`（外观模式切换）、3D 槽位导入文件对话框等。

### 渲染层 (app.js)
- 新增外观模式状态 `appearanceMode: '2d' | '3d'`。
- 模式切换时：2D 走现有 PixelEngine Canvas；3D 走新建 Pet3DRenderer（Three.js）。
- 两者共享同一透明窗口和同一套交互（拖动/戳宠物/气泡锚点）。

### 数据层
- 完全不变。等级/心情/记忆/设定/AI 对话/AI 提供商全部一个来源，3D 只是换渲染。

## 三个 3D 槽位

- 数据结构 `slots3D = [slot1, slot2, slot3]`，每个槽：
  ```
  { type: 'builtin' | 'glb', builtinId?, glbPath?, modelName }
  ```
- 默认：槽1=体素猫、槽2=体素兔、槽3=体素熊（代码生成，可替换）。
- 外观切换列表 = 现有像素皮肤 + 三个 3D 槽位，一起出现在切换界面。
- 槽位管理（导入/替换/清空）放在设置页。

## Pet3DRenderer（新文件 src/renderer/pet3d.js）

- 创建 THREE.WebGLRenderer（alpha:true 透明背景、antialias），挂到现有 #stage 容器。
- 场景：柔和环境光 + 主方向光，轻微阴影，让宠物有立体感。
- 相机：透视相机，固定微俯角（15~25°），宠物居中，可做轻微旋转展示。

### 体素宠物生成（voxel-compose.js 或复用 pixel-compose 数据）
- 读取现有 20×20 像素定义，把非空像素映射为方块：正面一层 + 挤出厚度（约 4~6 层），InstancedMesh 合批渲染。
- 耳朵/尾巴等部件在体素网格上按原像素布局堆叠，保持像素风。

### 动画（程序化驱动，与 2D 动画同一套交互钩子）
- 待机：呼吸缩放 + 尾巴轻微摆动 + 眨眼（方块组变换）。
- 戳宠物/拥抱：回弹挤压动画 + 触发 AI/预设气泡（完全复用现有逻辑）。
- 拖动：与现在一致，窗口位置更新。

### 外部 .glb 模型
- 用 GLTFLoader 加载，file:// 或磁盘读取；模型放入统一包围盒缩放适配窗口。
- 自带动画则播放其动画剪辑；否则套用基础待机旋转/浮动。

## 设置页与切换 UI

### 外观切换 UI（现有切换入口扩展）
- 现有皮肤切换界面扩成两层：像素皮肤（保留）+ 3D 外观（三槽位）。
- 点某个 3D 槽位 → 预览该模型的渲染缩略图（Three.js 离屏渲染一张小图）。
- 选中后立即切换宠物为 3D 渲染，数据不丢。

### 设置页 3D 区块
- 三个槽位卡片：显示当前模型名/类型 + 缩略图。
- 每个槽：`选择内置（猫/兔/熊）`、`导入 .glb 文件`（文件对话框）、`恢复默认`。
- 导入的模型存入应用数据目录（app.getPath('userData') 下 models3d/），记录路径到设置。

## 错误与回退

- .glb 文件损坏/加载失败 → 弹提示，槽位回退到内置款，不崩溃。
- 切换 3D 时若无 WebGL 支持 → 自动回退 2D 像素并提示。

## 实现顺序建议

1. 引入 Three.js 依赖（本地打包，避免外网 CDN）。
2. Pet3DRenderer 骨架：透明 WebGL 画布 + 场景/光照/相机 + 空场景可显示。
3. 体素宠物生成器：从 pixel-compose 数据生成体素宠物，待机动画。
4. 外观模式切换 + 设置持久化（slots3D）。
5. 三个内置槽位 + 切换 UI 两层列表。
6. 外部 .glb 导入/加载/缩放 + 动画。
7. 设置页 3D 区块（卡片/缩略图/导入/恢复默认）。
8. 错误回退 + 打包验证。
