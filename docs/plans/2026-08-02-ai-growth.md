# 智能对话 + 宠物人格/成长/记忆 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 扩展桌面宠物，实现 ①AI 智能对话（复刻 opencode 提供商配置、多配置可选模型/推理等级）②聊天记忆存档 ③启动自动打招呼 ④名字+主人称呼 ⑤年龄/生日/性别 ⑥成长系统（等级+经验+体型变化）。

**Architecture:** Electron 主进程（main.js）+ 渲染层（app.js 宠物窗口、chat.js 聊天窗、settings.js 设置页）。持久化用 JSON 文件（settings.json / state.json / memory.json）。AI 对话经主进程 `chatAI()` 调 OpenAI 兼容 `/chat/completions`。成长系统由宠物窗口统计交互经验并在 main 持久化体型系数。

**Tech Stack:** Electron 33, 原生 fetch, JSONIPC（ipcMain.handle/invoke）。无第三方依赖。

### Task 1: 智能对话提供商配置（复刻 opencode + 多配置 + 模型/推理等级 + 预设）

**设计（与 opencode 对齐）：**
- 每个 provider 结构：`{ id, name, baseUrl, apiKey, apiType:'openai'|'anthropic', models:[{model, reasoning:[低/中/高]}], defaultModel }`
- `activeProviderId` 当前生效；设置页可新增多个、可选用、可删除。
- 热门预设：内置若干 provider 模板（OpenAI/DeepSeek/OpenRouter/xAI/Groq 等）一键添加；同时把用户当前自定义配置也作为一条。
- 推理等级：请求体附加 `reasoningEffort`（openai 走 `reasoning_effort`）。

**文件：**
- Modify: `C:\wwwroot\cartoonwife\main.js`（chatAI 逻辑、providers 结构）
- Modify: `C:\wwwroot\cartoonwife\src\renderer\settings.html / settings.js`
- Test: `node --check` + CDP 设置页往返

关键代码（main.js chatAI 改造后）：
